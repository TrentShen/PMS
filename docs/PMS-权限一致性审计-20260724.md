# PMS 权限一致性专项审计（2026-07-24）

> 起因：员工访问试用期详情被前端守卫 403（已修，2668eba）。用户要求全面排查同类问题。
> 方式：两路并行审计——①路由守卫 ↔ 菜单 ↔ 页面 API ↔ 后端权限四方对照；②五种角色完整旅程走查。

## 结论总览

- 菜单 ↔ 路由守卫：**全部一致**（此前 /calibration、/probation 两处修复有效）。
- 流程断 1 个、口径相反 1 个、口径不一致/越权若干。根因集中在两点：
  1. 后端存在"有 `is_hr_dept_leader` 兜底（require_role）"和"无兜底（can_act_as_superior）"两套口径；
  2. 部分列表接口按 scope 过滤后被前端当"选人数据源"，员工 scope 只有自己 → 候选集恒空。
