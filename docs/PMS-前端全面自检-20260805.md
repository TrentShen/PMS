## 六、修复执行与复检结论(2026-08-05 当天完成)

用户决定:**全部修复**。P0+P1+高性价比 P2 共 30+ 项由 5 个并行代理 + 主代理完成,随后 2 个复检代理回归核查。

**验证**:pytest 194 全过(新增 7 个用例:非 FTE 守卫 4 + 状态白名单 3)、tsc 0 错、build 通过、ruff 通过、eslint 0 error。

**复检发现并已修的新问题**(修 A 坏 B 检查):
- **高危**:useMobile 断点 `<=768` 与 CSS `max-width:767px` 错位,iPad 竖屏(768px)下条件渲染走卡片分支但被 CSS 隐藏 → 校准/参与人表整块空白。已改为 `< 768` 并与 CSS 对齐(hooks/useMobile.ts)
- ObjectiveCycleDetail 加载失败永久 Spin → 加 loadError 错误态;ObjectiveCycleList 补 catch
- HrConsole 删除参与人补防重;ProtectedRoute 未登录跳登录补 redirect 参数;Calibration 空 items 时提交按钮禁用(非 FTE 场景);ValueGradeForm 硬编码 #fafafa 改令牌;formatError 多错误 \n 折叠改顿号分隔
- 复检发现的低危项:LeaderEvalDetail 互评汇总卡片 rowKey 拼接(冲突概率极低)、HrConsole 卡片点击与操作冒泡串扰——记 backlog

**复检结论**:所有申报修复项真实生效,无高危回归,可安全部署。

**有意不修**(记录在案):antd chunk 1.17MB 全量(无可靠瘦身途径)、首页重复请求(量级小)、StrictMode dev 双发、草稿 key 残留(每年数 KB)、Calibration 热力图 hsl 功能色、Login mock 页 ROLE_COLOR。

**产品意图已确认**:未开反馈环节不发布最终结果(后端 mask 保持,前端 Home 加"结果待发布"守卫);历史结果仅直属上级可见。
